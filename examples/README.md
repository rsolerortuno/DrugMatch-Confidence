# Example files

The trametinib and afatinib examples are real DepMap Public 26Q1 feature rows selected from their locked internal test partitions. They are provided only to demonstrate the software interface. The JSON outputs were generated by the bundled version 1.0.0 models.

Run:

```bash
drugmatch predict --model models/real/depmap_26q1_prism/trametinib.joblib --features examples/trametinib_example_input.csv
```
